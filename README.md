# AJ Picard portfolio

Public portfolio at https://ajpicard913.github.io.

The site is static HTML, CSS, and JavaScript. GitHub Pages publishes the root of the `main` branch.

- `index.html`: content and app links
- `style.css`: responsive presentation
- `main.js`: scroll animations and motion controls
- `assets/`: official app icons and screenshots

Preview locally with `python3 -m http.server 8000`.
